Student Performance Analysis

Project Overview

This project investigates the relationship between students' study hours and examination performance using Python and Linear Regression.

Objectives

- Explore the relationship between study hours and examination scores.
- Perform exploratory data analysis.
- Visualise patterns in the dataset.
- Build a Linear Regression model.
- Predict examination scores based on study hours.

Tools and Technologies

- Python
- Google Colab
- Pandas
- Matplotlib
- Scikit-learn

Preliminary Findings

- Average study time: 2.75 hours.
- Average examination score: 69.2.
- A positive relationship was observed between study hours and examination scores.
- The regression model produced a coefficient of approximately 8.70.

Limitations

The dataset contains only 10 observations. The model requires further evaluation using unseen data before it can be considered reliable for practical decision-making.
